# How we work

1. `git pull` on `main` before starting.
2. Create a branch: `git checkout -b feature/<short-name>` (example: `feature/chat-ui`).
3. Commit small and often with clear messages.
4. Push the branch and open a pull request on GitHub.
5. A teammate reviews it, then merge into `main`.

Branch names: `feature/...`, `fix/...`, `data/...`, `docs/...`
